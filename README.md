# API 管理助手

**把 16 家 AI 平台的 API 余额，汇总到手机桌面上的一个小组件里。**

纯代码查询 —— **不调用任何 AI 接口，不消耗一分钱 token**。

> Android 7.0+ ｜ 免费开源 ｜ 无需注册 ｜ 无广告 ｜ 无遥测 ｜ 只申请网络权限

## 为什么会有这个

同时用三家以上 AI API 的人都知道这件事有多烦：
收藏夹点开 → 登录 → 翻到余额页 → 换算汇率 → 心里加一遍。五个平台就是五分钟。

更麻烦的是**不知道什么时候会用完**——任务跑到一半接口返回 402，前面全白等。

想要的其实特别简单：**抬眼看一下桌面，就知道还剩多少钱。**

## 功能

### 桌面小组件

- **2 列网格**，按组件实际高度自动决定显示 4 个还是 6 个平台
- 每格：平台名 + 余额（外币金额旁边跟一行更小更淡的人民币折算）
- 平台超过一页容量时自动出现 `‹ 1/2 ›` 翻页按钮，**翻页不联网**（读本地缓存）
- 点组件任意位置 = 刷新
- 三种皮肤：**玻璃**（半透明，壁纸会透上来）/ **新拟物** / **简约**，跟随系统深浅色

### 余额总览

- 所有平台一张卡片，外币自动折合人民币，顶部大字是总资产
- 同一平台可以挂**多个 Key**（主力 / 备用 / 不同项目分开算），各自独立设阈值和统计开关
- 聚合口径：同平台多 Key **取最大值**（同一账户下不同 Key 查到的是同一份余额，相加会重复计算）

### 用量统计

- 余额折线图，范围可选 5 / 7 / 14 / 30 / 90 / 180 日
- **每 6 小时自动打一个快照**，存在本地 SQLite
- 消耗由快照差值推导，**充值自动识别**（余额突增时匹配最接近的充值档位），认错了可手动修正
- **点图表里某一天** → 列出那天各平台的余额明细
- 每个平台一行：`名称　充值 ¥x　消耗 ¥y`，底部汇总总充值 / 总消耗

### 自定义平台

任何 **OpenAI 兼容** 的平台都能接：填「名称 + 余额查询 URL + Key + 取值路径 + 币种」即可。
取值路径留空会自动识别；认不出来时卡片上**直接显示接口的原始返回**，照着填就行。

### 页面管理

四个页面可**排序 / 隐藏 / 设为主页面**（设置 → 📑 页面管理）。
设置页固定不可隐藏——隐藏相关的开关本身就在那里面。

### 小米 MiMo：只能登录，不能填 Key

MiMo 开放平台**没有可用的余额查询接口**——网关 `api.xiaomimimo.com` 上除了推理接口，
所有 billing / user / balance 路径实测全部 404。余额只存在于控制台，
而控制台的余额接口认的是**小米账号的会话音 cookie**（拿 `sk-xxx` 当 Bearer 一样 401）。

所以做法是应用内 WebView 登录：`设置 → API 密钥与平台 → 小米 MiMo → 登录小米账号`。
会话凭证用与 API Key 同一把设备密钥加密后存在本机，之后自动查余额。

> 判断登录成功的办法不是猜 cookie 名，而是**拿 cookie 真去调一次余额接口**——
> 小米会往该域塞好几个 cookie（有的登录前就存在），只有接口返回 200 才算数。

## 安装

1. 到 **[Releases](https://github.com/hesanyue50-lang/balance-widget/releases)** 下载最新的 `BalanceWidget.apk`
2. 手机上允许"安装未知来源应用"
3. 打开应用 → `设置` → `API 密钥与平台` → 填入你的 Key
4. 回到桌面，长按空白处 → 选择「小组件」→ 找到「API 余额」→ 拖到桌面合适位置

> ⚠️ **国内直连 GitHub 下载可能很慢甚至失败**，这个是没办法的事。
> 如果下不动，可以换个网络再试，或者……自己 clone 源码编译（见 [DEVELOP.md](DEVELOP.md)）。

> 部分国产桌面（如实测的 vivo）不支持应用内一键添加组件，
> 应用里点「添加到桌面」会弹出图文引导，照着做即可。

## 使用

| 手势 | 作用 |
|---|---|
| 左右滑动 | 切换页面（一次最多走一页，松手自动对齐） |
| 下拉刷新 | 余额页 / 统计页顶部下拉，统计页会连带重算图表 |
| 点卡片 | 刷新 / 看密钥 / 打开控制台 / 充值 |
| 长按卡片 | 调整卡片顺序 |
| 长按统计页的行 | 调整折线与开关顺序（与卡片顺序独立） |

| 长按设置里的密钥条目 | 查看 / 复制密钥（需先过查看密码） |

应用内 `设置 → ❓ 使用帮助` 有完整说明。

## 隐私

- API Key、小米会话凭证都用 **Android Keystore 设备级密钥 AES-GCM 加密**后存应用私有目录
  ——密钥本体生成在 TEE 里，**把 `/data/data` 整个目录拖走也解不开**
- 输入框强制密码掩码；查看密钥需要先过一道「查看密码」闸门
- **只发往两个地方**：你填了 Key 的平台的官方域名、以及汇率源
- **没有账号、没有服务器、没有埋点、没有广告 SDK**
- 历史账本全部本地存储，不外传
- 申请的权限只有：网络、网络状态、通知、开机自启、电池优化白名单

## 已知边界

- **组件尺寸由桌面决定**：声明 3 行格高，实测 vivo 桌面只给 2 格，所以做了按实际高度自适应行数
- 火山 / 星火 / InternLM / 阶跃等平台的字段名未经真实 Key 验证，已做深度遍历兜底；
  识别不出来时卡片会显示接口原始返回
- 小组件只用 RemoteViews 支持的控件（不能用自定义 View / ScrollView）
- **小米 MiMo 登录依赖官方控制台页面**：若小米账号强制短信验证、或页面拒绝 WebView，需要换登录方式
- **百炼（阿里云）** 走 BSS OpenAPI，需要 AccessKey 签名；订阅制没有余量 API
- 排序用 ▲▼ 而非拖拽：项目**无 androidx 依赖**（用不了 ItemTouchHelper），
  自写拖拽会与滚动容器抢手势
- 未设 `previewImage`，小组件选择器里显示的是应用图标

## 常见问题

**Q：需要 root 吗？**
不需要。普通应用 + 桌面小组件。

**Q：会不会偷偷用我的 Key 发请求花钱？**
不会。它只请求余额查询端点，代码里没有任何 Chat / Completions 调用。

**Q：我的 Key 会被上传到哪里？**
哪里都不去。加密存在手机私有目录，请求直接从你的手机发往平台官方域名。

**Q：为什么有些平台查不出来？**
火山方舟 / 讯飞星火 / 书生 / 阶跃这几家的字段名没有真实 Key 全量验证过。
识别不出来时卡片会**直接显示接口原始返回**——把那个截图发我，一天内就能适配好。

**Q：能出 iOS 版吗？**
桌面小组件的形态是照着 Android 做的，iOS 要重写一套，暂时没有计划。
